# 第一批保护修复：保持历史答题与评分行为

本批仅加固复测流程，不包含提分算法。对通过完整性检查的相同输入，保留历史 LongMemEval v7 和 BEAM I 的检索、材料、提示词、预算、模型参数与评分规则。新模型调用本身仍可能波动，不承诺每轮得分相同。

## 修改边界

- 审计以新的run ID及running状态开始，只有完整成功清单、对应报告哈希和run ID一致时才允许新跑。失败或中断不能回退使用旧成功报告。
- 实验协议绑定实际模型端点、数据库连接和服务配置快照的指纹。变更后拒绝复用旧目录；不保存明文凭据。
- 整次运行持有目录级跨进程锁，同目录第二个进程直接拒绝。
- 在调用模型前检查bank与评估材料。BEAM缺少rubric且答案为空时停止，不自行记0分。
- 核对数据库身份、bank配置与LME规范化源正文指纹。完整性错误直接终止，不发布新汇总成绩；原有普通模型技术失败仍按原协议保留在分母中。

历史输出不迁移、不覆盖。新版运行需新建输出目录、重新生成封存审计，并通过`--environment-report`提供本次服务配置取证。BEAM新跑也需要对应数据库只读连接。目录锁面向POSIX，本次目标环境是Linux ECS与macOS。

配置文件指纹证明的是所提供文件身份，不能自动证明代理后端模型未变。仍应在运行前采集当前配置，并按需在运行后重新审计。
